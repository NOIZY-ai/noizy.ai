
## WIDGET ULTRA-SHORTS

| Code | Action |
|------|--------|
| `/SS!` | Quick task - just do it |
| `/SS?` | Quick question - answer briefly |
| `/SS>` | Improve this |
| `/SS<` | Simplify this |
| `/SS@` | Draft a message to |
| `/SS^` | Prioritize these |

## PRO TIP

Save these as Text Replacements on iOS:

`Settings > General > Keyboard > Text Replacement`

| Shortcut | Phrase |
|----------|--------|
| `ssm` | /SS-MORNING |
| `ssc` | /SS-TURBO-CAPTURE |
| `ss911` | /SS-911-CODE |
| `ssauto` | /SS-AUTO |

Type the shortcut → it expands → paste into Claude → GO!
