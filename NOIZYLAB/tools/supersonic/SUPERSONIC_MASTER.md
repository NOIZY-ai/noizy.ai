## iOS SETUP GUIDE

### 1. Text Replacements (Fastest)

Settings > General > Keyboard > Text Replacement

| Shortcut | Phrase |
|----------|--------|
| `sssum` | /SS-SYS-SUM |
| `sscode` | /SS-DEV-CODE |
| `ssauto` | /SS-AUTO |
| `ss911` | /SS-911-CODE |

### 2. Shortcuts App

Create shortcuts that:
1. Accept input (text or voice)
2. Combine with SuperSonic prompt
3. Copy to clipboard
4. Open Claude app

### 3. Home Screen Widgets

Add Shortcuts widget with your top SuperSonic commands.

### 4. Back Tap (iPhone)

Settings > Accessibility > Touch > Back Tap

Set double/triple tap to trigger SuperSonic shortcut.

## PRO TIPS

### Speed Maximizers

1. **Chain codes**: Use output from one as input to another
2. **Voice-first**: Dictate, then clean with `/SS-TURBO-VOICE`
3. **Clipboard auto**: Copy text, run `/SS-AUTO`
4. **Widget access**: Put top 4 codes on Home Screen

### Quality Boosters

1. **Add context**: More detail = better results
2. **Specify format**: Tell Claude exactly how you want output
3. **Iterate**: Refine with `/SS>` (improve this)

### NOIZY Integration

1. **Voice projects**: Start with `/SS-TURBO-VOICE-PROJECT`
2. **Consent tracking**: Use `/SS-NOI-FISH` for all voice work
3. **Guild progress**: Track with `/SS-NOI-VOX`
