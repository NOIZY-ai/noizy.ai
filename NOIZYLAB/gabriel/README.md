## Quick Start

### Option 1: Gabriel CLI

```bash
gabriel status        # Show system status
gabriel doctor        # Run diagnostics
gabriel dreamchamber  # Launch DreamChamber
gabriel speak "text"  # Text to speech
gabriel activate      # Activate all systems
```

### Option 2: Master Activation

```bash
./MASTER_ACTIVATE.sh       # Check all systems
./MASTER_ACTIVATE.sh -f    # Full activation with DreamChamber
```

### Option 3: Direct Python

```bash
python3 GORUNFREEX1000.py           # Interactive launcher
python3 brain/god_brain.py          # God Brain
python3 core/dreamchamber.py        # DreamChamber
python3 core/visual_scanner.py      # Visual Scanner
```

## AI Workers (TypeScript)

The `workers/` directory contains the TypeScript AI system:

- **UnifiedAIWorker** - Single API for all AI interaction
- **AiOrchestration** - Intelligent agent routing
- **PatternIntelligence** - Anomaly detection & prediction
- **KnowledgeGraphAI** - Auto-building knowledge base

### Build & Run

```bash
cd workers
npm install
npm run build
npm run dev
```

## Shell Integration

Add to your `.zshrc` or source `~/.config/zsh/30_gabriel.zsh`:

```bash
export GABRIEL_ROOT="$HOME/NOIZYLAB/GABRIEL"
export PATH="$GABRIEL_ROOT/bin:$PATH"

# Quick commands
alias gab='gabriel'
alias godbrain='python3 $GABRIEL_ROOT/brain/god_brain.py'
alias dreamchamber='python3 $GABRIEL_ROOT/core/dreamchamber.py'
```
