## 🔧 Polyglot Techniques

### Comment Exploitation
| Language | Line Comment | Block Comment |
|----------|--------------|---------------|
| Python | `#` | `"""..."""` |
| Ruby | `#` | `=begin...=end` |
| Perl | `#` | `=pod...=cut` |
| Lua | `--` | `--[[...]]` |
| C/C++/JS | `//` | `/*...*/` |
| Bash | `#` | `: <<'EOF'...EOF` |
| PHP | `//` `#` | `/*...*/` |
| SQL | `--` | `/*...*/` |
| Haskell | `--` | `{-...-}` |

### Execution Order Tricks
1. **Shebang** - `#!/bin/bash` ignored by most languages
2. **Heredocs** - Bash `: << 'END'` hides code
3. **String literals** - `"""` in Python vs syntax in others
4. **Preprocessor** - `#if 0` hides C code
5. **Exit early** - `exit`, `die`, `__END__`

## 🧠 How It Works

```
┌─────────────────────────────────────────────┐
│              POLYGLOT FILE                  │
├─────────────────────────────────────────────┤
│  #!/bin/bash         ← Shell sees shebang  │
│  #/* ... */          ← C sees comment      │
│  """..."""           ← Python sees string  │
│  =begin...=end       ← Ruby sees comment   │
│  --[[...]]           ← Lua sees comment    │
│  =pod...=cut         ← Perl sees POD       │
├─────────────────────────────────────────────┤
│  Each language "sees" its own valid code   │
│  while ignoring code meant for others!     │
└─────────────────────────────────────────────┘
```
