## 🎯 USAGE

### **Auto-Detect Language:**
```python
from gabriel_multilingual import GabrielMultilingual

gabriel = GabrielMultilingual()
response = gabriel.process_input("Hola! ¿Cómo estás?")
# Auto-detects Spanish and responds in Spanish
```

### **Manual Language Selection:**
```python
gabriel.set_language('es')  # Spanish
response = gabriel.process_input("Hello!")
# Responds in Spanish even if input is English
```
