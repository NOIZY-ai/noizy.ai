## 🚀 QUICK START COMMANDS

### **1. Verify Installation:**
```bash
python3 verify_installation.py
```

### **2. List Services:**
```bash
python3 voice_ai_pro.py --list
```

### **3. Generate Voice:**
```bash
# Free services
python3 voice_ai_pro.py --generate "Hello!" --service gtts
python3 voice_ai_pro.py --generate "Hello!" --service edge
python3 voice_ai_pro.py --generate "Hello!" --service pyttsx3

# Ultra performance
python3 voice_ai_ultra.py --generate "Hello!" --service edge
```

### **4. Audio Processing:**
```bash
python3 voice_ai_ultra.py --optimize audio.mp3
python3 voice_ai_ultra.py --enhance audio.mp3
```

### **5. Web Interface:**
```bash
python3 voice_ai_web.py
# Open http://localhost:5000
```

### **6. API Server:**
```bash
python3 voice_ai_api_server.py
# Open http://localhost:8000/docs
```

### **7. Voice Cloning:**
```bash
python3 voice_cloner.py --clone sample.mp3 --name "Voice" --service elevenlabs
```

### **8. Transcribe Audio:**
```bash
python3 voice_ai_pro.py --transcribe audio.mp3
```
