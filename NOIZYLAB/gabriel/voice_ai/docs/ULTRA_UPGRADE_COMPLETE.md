### **Voice Cloning:**
```bash
# Clone voice from audio
python3 voice_cloner.py --clone sample.mp3 --name "My Voice" --service elevenlabs

# Generate with cloned voice
python3 voice_cloner.py --generate "Hello!" --voice-id VOICE_ID
```

### **REST API:**
```bash
# Start API server
python3 voice_ai_api_server.py

# Generate voice via API
curl -X POST "http://localhost:8000/api/generate" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello!", "service": "gtts"}'

# Transcribe audio
curl -X POST "http://localhost:8000/api/transcribe" \
  -F "file=@audio.mp3"
```
