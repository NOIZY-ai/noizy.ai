## 🚀 QUICK START

### **Core (Basic):**
```bash
cd GABRIEL/core
python3 voice_ai_universal.py --list
python3 voice_generator.py "Hello!" --voice en-US-AriaNeural
```

### **Advanced:**
```bash
cd GABRIEL/advanced
python3 voice_ai_pro.py --generate "Hello!" --service edge
python3 voice_cloner.py --clone sample.mp3 --name "Voice"
```

### **Ultra (Zero Latency):**
```bash
cd GABRIEL/ultra
python3 voice_ai_optimized.py --generate "Hello!" --service edge
python3 voice_ai_ultra.py --generate "Hello!" --service edge
```

### **Web Interface:**
```bash
cd GABRIEL/web
python3 voice_ai_web.py
# Open http://localhost:5000
```

### **API Server:**
```bash
cd GABRIEL/api
python3 voice_ai_api_server.py
# Open http://localhost:8000/docs
```
