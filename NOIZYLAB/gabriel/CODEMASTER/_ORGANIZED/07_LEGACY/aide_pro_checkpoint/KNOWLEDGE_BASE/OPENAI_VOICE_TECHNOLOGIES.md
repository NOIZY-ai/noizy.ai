## 1. Text-to-Speech (TTS) Models

**Purpose:** Convert written text into natural-sounding spoken audio.

- **Built-in Voices:** 11
- **Multi-Language Support:** Yes
- **Primary Model:** `gpt-4o-mini-tts`

## 2. GPT-4o mini TTS

**Role:** Current primary model for text-to-speech.

- **Quality:** High
- **Efficiency:** Optimized for speed and cost

## 3. Realtime API / gpt-realtime

**Role:** Low-latency, speech-to-speech interactions.

- **Use Case:** Responsive AI voice agents
- **Capabilities:**
    - Natural conversation flow
    - Interruption handling
    - Emotional cue detection

## 4. Voice Engine

**Role:** Text-to-speech with voice cloning.

- **Requirement:** 15-second audio sample
- **Output:** Natural-sounding voice replica

> [!CAUTION]
> **ACCESS RESTRICTED.** Not widely released due to deepfake/impersonation risks. Available to select partners only.

## 5. GPT-4o (Omni)

**Role:** Flagship multimodal model with native audio I/O.

- **Capabilities:**
    - Real-time voice conversations
    - Non-verbal cue understanding
    - Emotional response generation
- **Integration:** Native to ChatGPT application
