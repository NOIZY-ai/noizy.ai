# MIACLE BULLET COMPRESSOR

**Goal:** Condense any content into bullet points that are:

* Decisive
* Actionable
* Zero fluff
* Minimal words
* Maximum signal

**Rules:**

* **Max 12 bullets**.
* Each bullet must include a **verb + object** (e.g., "Index stems by LUFS + tempo").
* If uncertain -> include "**VERIFY:**" bullet instead of guessing.

**Output JSON:**

```json
{
  "miacle_bullets": [],
  "next_actions": [],
  "risks": [],
  "verify": []
}
```
